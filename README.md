# Lunara

Lunara is an open-source YouTube Music player for Android. This build is
based on [Metrolist](https://github.com/MetrolistGroup/Metrolist) — its
InnerTube extraction (innertubex + zemer-cipher), streaming pipeline,
offline cache and Compose UI are used here with thanks to the Metrolist
project and its inspirations (InnerTune, OuterTune and the wider
community).

## Download

Grab the latest `lunara-v*.apk` from the repository's Releases page.
Builds are signed with a stable key and update in place over earlier
Lunara installs.
